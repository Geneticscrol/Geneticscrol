## 🧠 About Me

The arc: built websites → learned to break them → learned to harden them → now exploring where **AI meets security and defense tech**.

I'm a self-taught technologist from Vadodara, India. I've been doing ethical hacking since 2020, running Linux on everything I own, and spending way too much time making AI run locally on hardware it has no business running on.

- 🔐 &nbsp;Ethical hacking & penetration testing since 2020 — CTFs, bug bounties, full Kali toolkit
- 🤖 &nbsp;Exploring the AI × defense technology intersection — where model reliability under adversarial conditions actually has real consequences
- 🐧 &nbsp;Arch Linux daily driver · WSL2 on Windows · Heavy Linux server administration experience
- ⚡ &nbsp;50+ personal CLI automation tools · 10+ open source projects on GitHub
- 🌐 &nbsp;Google Student Ambassador · Perplexity Campus Partner
- 🎯 &nbsp;Currently: Anthropic Fellows Program applicant
